# Deck: From Bug to Insight

Open [`template.html`](template.html) in a browser (Chrome or Edge). Use the keyboard, the mouse, or the scroll wheel to present.

Each advance first reveals the next block on the current slide (agenda rows, pillars, architecture panels, demo steps, and so on). After the last block, it goes to the next slide. Going back hides the last block, or returns to the previous slide with everything already visible.

| Key / action | What it does |
|---|---|
| Click, ↓, →, Space, scroll down | Reveal next block, then next slide |
| ↑, ←, scroll up | Hide last block, then previous slide |
| Home / End | First / last slide (resets that slide) |
| Dots on the right | Jump to a slide and start it from the first block |

The footer hint shows `CLIC / → REVELA · 2/6` while a slide still has hidden blocks. The counter is `01 / 22`.
